# CHAT 部署手冊

**給完全沒寫過程式的人。** 照著做，就會有一個屬於自己的家族聊天室網址。

- 需要時間：約 20 分鐘（只有第一次需要）
- 需要費用：**0 元**，不用綁信用卡
- 程式碼已經在你的 GitHub（`yuyangmoney-stack/chat`）裡了，
  接下來只要**註冊 Cloudflare、設定兩個值、按一個按鈕**

## 一、先看懂這幾個名詞

| 名詞 | 白話解釋 |
|---|---|
| **GitHub** | 放程式碼的地方。你的程式碼在 `yuyangmoney-stack/chat` 這個 repo 裡，它也負責「按一個按鈕就幫你部署」。 |
| **Cloudflare** | 網站實際運作、存資料的地方。用免費方案就夠。 |
| **Worker** | Cloudflare 上跑程式的單位。你的聊天室就是一個叫 `chat` 的 Worker。 |
| **Token（權杖）** | 「給程式用的密碼」。GitHub 要拿它去操作你的 Cloudflare。可以隨時撤銷，而且**只會顯示一次**。 |
| **Secret** | 存在 GitHub 裡、加密保管的值。存進去之後連你自己都看不到內容，只能覆蓋或刪除。 |
| **部署** | 把程式送上 Cloudflare，讓網址可以打開。 |

## 二、註冊 Cloudflare

1. 打開 <https://dash.cloudflare.com/sign-up>
2. 填 Email 和密碼 → 註冊 → 去信箱點驗證連結。**不需要信用卡。**
3. 登入後，左邊選單點 **Workers & Pages**。
4. **第一次進來會請你取一個子網域名稱。** 這會變成你網址的一部分：
   - 填 `lin-family`，網址就是 `https://chat.lin-family.workers.dev`
   - 取好之後不太好改，想清楚再填
   - 用英文小寫和連字號，不要太短
5. **開啟兩步驟驗證**：右上角頭像 → **My Profile** → **Authentication**
   → **Two-Factor Authentication**，照畫面設定。
   > 這個帳號就是你全家聊天記錄的鑰匙，**請不要跳過**。

## 三、拿 Account ID 和 Token

先開一個記事本，等一下要暫時貼兩個值（做完就刪掉）。

### Account ID

1. Cloudflare → **Workers & Pages**
2. 頁面右側找到 **Account ID**，按旁邊的複製鈕
3. 貼到記事本，標註「Account ID」

### API Token

1. Cloudflare 右上角頭像 → **My Profile** → 左邊 **API Tokens**
2. 按 **Create Token**
3. 範本列表找 **Edit Cloudflare Workers** → 按 **Use template**
4. 往下找 **TTL**（有效期限），建議設**一年後**
5. 其他不用改，滑到最底 → **Continue to summary** → **Create Token**
6. ⚠️ **畫面上那串很長的英數字就是 Token，只會出現這一次。**
   馬上複製，貼到記事本，標註「Token」。

---

## 四、把兩個值存進 GitHub

1. 打開 <https://github.com/yuyangmoney-stack/chat>
2. 上方 **Settings** → 左邊 **Secrets and variables** → **Actions**
3. 按 **New repository secret**，新增**兩個**：

| Name（要一字不差） | Secret（值） |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 剛剛的 Token |
| `CLOUDFLARE_ACCOUNT_ID` | 剛剛的 Account ID |

每個都要按 **Add secret**。

> 名稱全部大寫、用底線，打錯一個字就會部署失敗。
>
> 存好之後，**把記事本裡的 Token 刪掉**。

順便替 GitHub 帳號開兩步驟驗證：右上角頭像 → **Settings** →
**Password and authentication** → **Two-factor authentication**。

---

## 五、按下部署

1. 打開 <https://github.com/yuyangmoney-stack/chat> → 上方 **Actions** 分頁
2. 左邊選「**部署到 Cloudflare**」
3. 右邊按 **Run workflow** → 跳出小框後再按綠色的 **Run workflow**
4. 等一兩分鐘：
   - 🟡 黃色圓圈：還在跑
   - ✅ 綠色勾勾：成功！
   - ❌ 紅色叉叉：點進去看錯誤訊息，對照[疑難排解](#十二疑難排解)
5. 你的網址是 `https://chat.你的子網域.workers.dev`
   （也可以在 Cloudflare 的 **Workers & Pages** 裡點 `chat` 看到）

## 六、⚠️ 部署完成後立刻做這件事

**第一個註冊的人會自動成為管理員**，而在那之前，任何打開網址的人都能註冊。
從部署完成到你註冊之間，誰先找到網址，誰就是這個聊天室的永久管理員。

所以：

1. **馬上**打開你的網址
2. 點「**註冊**」
3. 填帳號（3–20 個小寫英文字母／數字／底線）、暱稱（可以用中文）、密碼（至少 6 個字）
4. 送出 → 你就是管理員 👑

之後沒有邀請碼的人就無法註冊了。

---

## 七、邀請家人加入

1. 網頁裡點 **設定** → 找到 **管理員** 區塊
2. 在邀請碼欄位填一組（例如 `lin888`）→ **儲存**
3. 按「**複製邀請訊息**」，它會把網址、步驟、邀請碼組好
4. 用 LINE 或簡訊傳給家人

家人註冊後，系統會**自動建立一個跟你的聊天室**。

**家人都進來之後**，把邀請碼清空再儲存，就等於關閉註冊。
已經註冊的人不受影響；之後要加人再臨時填一組。

---

## 八、之後要怎麼更新

程式碼有修改時（例如請別人或 AI 幫你改了東西），到 **Actions** →
**部署到 Cloudflare** → **Run workflow** 再按一次就好。

**更新不會弄丟任何資料。** 訊息、帳號、照片都存在 Cloudflare 的資料庫裡，
換程式碼不會動到它們。

---

## 九、備份聊天記錄

⚠️ **系統不會自動備份。** 請每一兩個月做一次：

**設定** → **管理員** → **下載聊天備份** → 存到你平常用的雲端硬碟。

重要的照片請另外單獨存一份。

## 十、安全守則

| ✅ 要做 | ❌ 不要做 |
|---|---|
| Cloudflare、GitHub 都開兩步驟驗證 | 把 Token 傳給任何人、截圖、貼在聊天室 |
| Token 只放在 GitHub Secrets | 把 Token 寫進程式碼或 README |
| Token 設到期日，不用了就到 Cloudflare 刪掉 | 長期不備份 |
| 家人都註冊完就關閉邀請碼 | 管理員密碼設得太簡單 |

**你需要知道的事：** 聊天內容**沒有端對端加密**，存在你的 Cloudflare 帳號裡，
能登入那個帳號的人就讀得到。管理員可以匯出全部記錄、重設任何人的密碼。

## 十一、費用會不會爆

**不會。Cloudflare 免費方案不會給你帳單。**

超過免費額度時，Cloudflare 的做法是**讓那類操作暫時失敗**，不是繼續跑然後寄帳單。
要開始計費，你必須**主動**升級到付費方案。

| 項目 | 每天免費（台灣時間早上 8 點重置） |
|---|---|
| 請求數 | 100,000 次 |
| 資料寫入 | 100,000 列 |
| 儲存空間 | 5 GB |

一家十個人以內用，一天大概幾千次請求。照片會壓到 450KB 以內，
5GB 大約可以放一萬張，幾年內不會是問題。

GitHub 也是免費的。

## 十二、疑難排解

| 症狀 | 原因與解法 |
|---|---|
| 部署失敗，說少了 secret | 兩個名稱要一字不差：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`。常見錯誤是多了空白或拼錯 |
| 部署失敗，錯誤裡有 `workers.dev subdomain` | Cloudflare 還沒取子網域。回[第二章](#二註冊-cloudflare)第 4 步，取好後再 Run workflow |
| 部署失敗，錯誤裡有 `Authentication`、`Unauthorized` | Token 錯了、過期或被刪了。照[第三章](#三拿-account-id-和-token)建一個新的，到 GitHub Secrets 點 `CLOUDFLARE_API_TOKEN` 旁邊的筆更新 |
| 打開網址是 404 | 還沒部署成功過，或子網域沒設定 |
| 改了程式但網站沒變 | 先到 Actions 確認部署是綠勾。手機把 App 完全關掉再打開；電腦按 Ctrl+Shift+R（Mac 是 Cmd+Shift+R） |
| 家人說邀請碼不對 | 邀請碼有分大小寫。請用「複製邀請訊息」，不要手打 |
| 連續輸錯被鎖住 | 密碼連錯 8 次鎖 10 分鐘，邀請碼連錯 5 次鎖 15 分鐘。這是防止別人亂猜的保護，等時間過了就好 |
| iPhone 收不到通知 | 一定要用 **Safari**「加入主畫面」，並且**從主畫面的圖示**開啟，才能開離線推播 |

還是卡住的話，把錯誤訊息完整複製下來再問人，錯誤訊息通常已經寫了答案。

## 附錄：用自己的電腦部署

不想用 GitHub Actions 的話，也可以在自己的電腦上部署（只需要做第二章，不用做三、四章）。

1. 安裝 [Node.js](https://nodejs.org/)（下載 LTS 版本，一路下一步），裝完重新開機
2. 打開命令列（Windows：開始 → 輸入 `cmd`；Mac：搜尋「終端機」）
3. 一行一行貼上，每行按 Enter：

```bash
git clone https://github.com/yuyangmoney-stack/chat.git
cd chat
npm install
npx wrangler login
npx wrangler deploy
```

- `git` 找不到的話，先到 <https://git-scm.com/> 安裝
- `npx wrangler login` 會打開瀏覽器請你授權 Cloudflare，按 **Allow**
- 最後一行跑完會印出你的網址
- Windows 的 PowerShell 如果說「已停用指令碼執行」，改用「命令提示字元（cmd）」

部署完一樣要**立刻做[第六章](#六️-部署完成後立刻做這件事)**。
